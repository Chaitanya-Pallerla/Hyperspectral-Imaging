## Overview

This repository brings together hyperspectral imaging research projects focused on food and agricultural applications, including fruit, poultry, microbial colonies, and rice.

Each application has its own directory containing available code, analysis workflows, and project-specific documentation.

## Getting Started

1. Select the research application relevant to your work.
2. Open the corresponding project directory.
3. Review the project-specific README.
4. Follow its available instructions for data processing and analysis.
